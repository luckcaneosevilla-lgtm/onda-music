Volver a ONDA

Conecta YouTube.

La búsqueda necesita una clave de YouTube Data API v3 en el servidor. No hace falta conectar tu cuenta de YouTube ni configurar OAuth para consultar vídeos públicos.

  1. Abre Google Cloud Console y crea o selecciona un proyecto.
  2. En APIs y servicios → Biblioteca, busca YouTube Data API v3 y pulsa Habilitar.
  3. En Credenciales → Crear credenciales → Clave de API. Si se abre el asistente, elige Datos públicos.
  4. Edita la clave: en Restricciones de API, selecciona Restringir clave y YouTube Data API v3. Como las consultas salen del backend, las restricciones por sitios web/HTTP Referer no sirven. Para un servidor con IP de salida estable, restringe por esa IP. En local con IP dinámica, comienza solo con la restricción de API y protege la clave.
  5. En la carpeta de ONDA, copia .env.example a .env. Sustituye el valor vacío de YOUTUBE_API_KEY por tu clave. No la añadas al frontend, no la publiques y no la envíes por el chat.
  6. Detén el servidor anterior con Ctrl+C y ejecuta python server.py --port 8765. Recarga ONDA y busca Feid.

Ejemplo de .env

YOUTUBE_API_KEY=tu_clave_real
YOUTUBE_REGION=ES
ONDA_SECURE_COOKIE=0

La clave solo la usa el servidor para las solicitudes oficiales. ONDA muestra un aviso si falta, se rechaza o se agota la cuota. No ofrece resultados ficticios como sustitución.

Cuota y disponibilidad

Revisa las cuotas vigentes del proyecto en Google Cloud. Cada página nueva solicita búsqueda y detalles de vídeos; repetir una consulta reciente puede usar la caché de 10 minutos. La reproducción usa el reproductor oficial, admite publicidad y depende de YouTube, la región y el navegador.

En iPhone puede ser necesario pulsar Play dentro del vídeo. No se ofrecen descargas, extracción de audio ni reproducción con pantalla bloqueada.
